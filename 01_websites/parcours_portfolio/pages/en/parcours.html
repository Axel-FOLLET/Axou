What each field taught me

  • Python

    Python piscine: Linux terminal and Git, then Python (conditions, loops, functions, files). Applied first in a language detector and Caesar and Vigenère ciphers, based on letter frequency, then, as personal projects, in two complete games: Hangman and Snake.

    Challenge met: recovering a Caesar key without being given it; the method is on its card in My portfolio.

  • Web

    The web, from page to live website.

    Web piscine: Bash scripts, semantic HTML pages, mobile-first Flexbox and Grid layouts, W3C validation. Then the resume website, with my first JavaScript interactions, and my portfolio: SEO, accessibility and automatic publishing with GitHub Pages. One file per responsibility (menu, cubes, form, games) taught me how the parts talk to each other. When a bug appears, I fix the cause rather than the symptom, without side effects on the rest of the site.

    Challenge met: pages that stay readable from large screens to phones, fully usable with the keyboard.

  • Project management

    Leading a team project.

    On the Job Board, presented in My portfolio, I led the project: schedule, daily tasks with an estimated workload for each member, a review before each merge, then deployment on Render.

    Challenge met: bringing a third member into the project mid-way by redistributing the work.

  • AI

    Leading a team of AI agents.

    Missions handed to several agents, following the method presented in My portfolio. Testing ground: Lost, a 3D browser game.

    Challenge met: turning an idea into a precise mission brief, to get concrete progress that meets my expectations.
