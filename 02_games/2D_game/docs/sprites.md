# Game sprites

Which image the game shows for each element, in each state or stage. The elements and stages follow [`rules.md`](rules.md) (§6 to §9). The paths in the code are listed in `core/src/main/java/com/cropa/view/SpriteCatalog.java`.

- **One image per state.** Every image in `assets/`, except the tile sheets of the map, is a separate file.
- **The direction used in the game.** The file name starts with the direction the element faces:
  - the enemies come from the right and walk towards the farm: `west-`; when they flee, they are seen from behind: `east-`;
  - the farm faces the enemies: `east-`;
  - the crops, the scarecrow, the cat and the bubbles face the player: `south-`; the catapatates face the field (see "Defenses").
- **"Team" pack:** image generated by the team with Pixel Lab. The tile sheets of the map are described in "Map".

## Map

The map `assets/maps/map_v1.tmx` draws its layers with 4 sheets of 16 x 16 tiles, stored in `assets/maps/assets/`. Each sheet has its `.tsx` file in `assets/maps/`, and the map gives the place of each tile.

These four sheets were drawn after the project, for this public copy of the game. They replace sheets from third-party packs whose licences forbid redistribution, and keep their file names, sizes and tile positions, so the map did not change. Each tile is a pixel grid written in a small Java program, made with Codex, an AI tool. Only the tiles used by the map are drawn: the other cells are empty, except in the grass sheet, where every cell holds the same grass tile.

| Element | Layer | File | Sheet | Tiles used | Pack |
| --- | --- | --- | --- | --- | --- |
| Grass | `floor` | `assets/maps/assets/tileset_grass_spring.png` | 48 tiles (192 x 64) | 33 | Own |
| Field soil and path | `farmland` | `assets/maps/assets/farmland_tile.png` | 9 tiles (48 x 48) | 0 to 8: corners, edges and centre | Own |
| Fences | `fences` | `assets/maps/assets/fences_copiar.png` | 15 tiles (48 x 80) | 0 and 6: rails to the right; 2: rails to the left; 3 and 5: post alone; 7: rails on both sides | Own |
| Decor | `flowers` | `assets/maps/assets/outdoor_decor_free.png` | 84 tiles (112 x 192) | 14: tree stump; 72: pot with a pink flower; 80: pot with yellow flowers | Own |
