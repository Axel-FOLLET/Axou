01 / Progress

From project management to development

After several years in human resources, including two leading change management at SFR Distribution, I joined Epitech in 2026 to train in a field that has always appealed to me. This portfolio records my progress: what I built and what each project taught me.

My goal: keep progressing across the different fields of IT, with a keen interest in IT project management and data science.

  1. 01

    The starting point

    Recruitment (BPCE, OCP), HRIS (Natixis), then HR and change management project manager at SFR Distribution, alongside a double master's degree in HR management (2022-2024). Planning, prioritising, supporting teams: these methods now structure my technical projects.

  2. 02

    Python basics

    Python bootcamp: Linux terminal and Git, then Python (conditions, loops, functions, files). Applied first in a language detector and Caesar and Vigenère ciphers, based on letter frequency, then, as personal projects, in two complete games: Hangman and Snake.

  3. 03

    The web, from page to live website

    Web bootcamp: Bash scripts, semantic HTML pages, mobile-first Flexbox and Grid layouts, W3C validation. Then the resume website, with my first JavaScript interactions, and this portfolio: SEO, accessibility and automatic publishing with GitHub Pages.

    Challenge met: pages that stay readable from large screens to phones, fully usable with the keyboard.

  4. 04

    Leading a team project

    Y.I.A Jobs, a job board built by a team of three: I led the project and developed the front end in React, my first framework. Schedule, daily tasks with an estimated workload for each member, an API contract between front end and back end, a review before each merge, then deployment on Render.

    Challenge met: bringing a third member into the project mid-way by resharing the work.

Working with AI: Claude and Codex

Since September 2026, I have been building the framework my AI agents, Claude and Codex, work in. Three goals, in this order: accurate data, controlled freedom for the agents, optimised use. The setup has become a short core with modules loaded when needed.

  • Shared rules

    One source for both assistants: a core read in every conversation (accuracy, communication, permissions), then eleven modules, from guidance to security, loaded when their topic comes up.

  • Levels of evidence

    Every statement declares its level: observed, reported by me, hypothesis or proposal. A figure cites its source; a report separates what was observed from what was inferred.

  • Skills

    Six methods shared by Claude and Codex: explaining code, finding the reason behind a choice, designing before writing, reviewing a change, guiding a regression test, teaching at my pace. Alongside them, rule modules such as writing: nine rules and my own style, drawn from my master's thesis.

  • Hooks

    Automatic checks at each step: rules recalled with every message, file writes refused without a recognised approval, then invisible characters and image metadata flagged. Automated tests check them.

  • Multi-agent team

    For delegated work, four separate roles: the manager writes the mission order with me, the project lead splits and checks the work, agents carry it out, and an expert runs a blind review. Without a “compliant” verdict, nothing is delivered.

  • Learning log

    A written record of each session, quizzes marked on content and spaced reviews: difficulties come back sooner, mastered topics less often.

Caesar and Vigenère ciphers

  • Python
  • Algorithms
  • Strings
  • Frequency analysis

Python bootcamp exercise: encrypting and decrypting with Caesar (fixed shift) and Vigenère (shift given by a keyword), then recovering a Caesar key on its own.

Key takeaway

The modulo wraps the alphabet and a single function handles both encrypting and decrypting. To break Caesar, I try all 26 keys and keep the text closest to French, as in the language detector.

Language detector

  • Python
  • Dictionaries
  • Statistics
  • Unicode

Python bootcamp exercise: recognising the language of a text among ten by comparing the frequency of its letters with that of each language. The demo reuses the program, ported to JavaScript.

Key takeaway

A statistical method needs volume: reliable from two sentences on, it hesitates on a few words. Accents also skewed the count, so I reduce them to their base letter before the analysis.
