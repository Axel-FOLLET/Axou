CHALLENGES OVERCOME

Challenges overcome

  • 3D display adapted to every screen

    Adapting the 3D cubes to every screen size without hiding the content required repositioning elements per screen. The result is a consistent rendering on desktop, tablet and mobile.

  • Readable, structured code

    To keep the code easy to read, I adopted the BEM convention, separated HTML, CSS and JavaScript and commented every file.

  • Accessibility and SEO

    Compliant contrast, full keyboard navigation, alternative texts and SEO tags were built in from the design stage.

  • Fast skill development

    Changing careers, I built solid foundations in Python then web development through concrete projects, relying on my project management rigour.
