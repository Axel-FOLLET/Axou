PROGRESS

From project management to development

After several years in human resources, including two managing change projects at SFR Distribution affecting up to 3,000 employees, I joined Epitech in 2026 to train in a field that has always appealed to me. I bring with me what project management taught me.

My goal: keep progressing across the different fields of IT, with a keen interest in IT project management and data science.

  1. 01

    The starting point

    Recruitment (BPCE, OCP), HRIS (Natixis), then HR and change management project manager at SFR Distribution, alongside a double master's degree in HR management (2022-2024). Planning, prioritising, supporting teams: these methods now structure my technical projects.

  2. 02

    Python basics

    Python bootcamp: Linux terminal and Git, then Python (conditions, loops, functions, files). Applied first in a language detector and Caesar and Vigenère ciphers, based on letter frequency, then in two complete games, Hangman and Snake.

    Challenge met: each project built on the previous one, from Hangman to Snake.

  3. 03

    The web: HTML and CSS

    Web bootcamp: Bash scripts, semantic HTML pages, mobile-first Flexbox and Grid layouts, W3C validation.

    Challenge met: pages that stay readable from large screens to phones.

  4. 04

    JavaScript and interactions

    Web bootcamp resume website: first JavaScript interactions, animated 3D cubes, a contact form and a bilingual version.

    Challenge met: 3D cubes that never hide the text, on every screen.

  5. 05

    A complete, online website

    This portfolio: four pages linked by clear navigation, SEO, accessibility and automatic publishing with GitHub Pages.

    Challenge met: full keyboard navigation and structured code, one file per responsibility.

  6. 06

    What comes next

    Keep progressing across the different fields of IT, with two areas I am drawn to: IT project management and data science.
