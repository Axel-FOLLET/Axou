My resume website

Context
Epitech web bootcamp project: design a resume website with HTML, CSS and JavaScript, without any framework, in French and English.
Goal
Present my move from HR project management to IT on a responsive, interactive and bilingual website, with a working contact form.
Key takeaway
One file per responsibility (menu, cubes, form, games) forced me to understand how each part talks to the others. When a bug appears, I know where to look and why it happens: I fix the cause rather than the symptom, without side effects on the rest of the site.

Snake game

Context
Personal project, built after Hangman to move from a turn-based game to a real-time one.
Goal
Develop a complete Snake: keyboard movement, collisions, apples, score and visual effects. The playable version here is adapted to JavaScript.
Key takeaway
Real time forces a clear split between the game loop, the display and the rules. The code is divided into modules (snake, apple, collisions, score): a rule can be fixed without touching the rest.
Skills and technologies
  • Python
  • Pygame
  • Keyboard events
  • Collisions
  • Code split into modules

Caesar and Vigenère ciphers

Context
Python bootcamp exercise: program two historical ciphers, then break the first one without knowing its key.
Goal
Encrypt and decrypt a message with Caesar (fixed shift) and Vigenère (shift given by a keyword), and recover a Caesar key on its own through frequency analysis.
Key takeaway
The modulo wraps the alphabet from "z" back to "a", and decrypting means shifting the other way: a single function handles both operations. To break Caesar, I reused the frequency comparison from the language detector: try all 26 keys and keep the text closest to French.
Skills and technologies
  • Python
  • Algorithms
  • Strings
  • Frequency analysis
  • JavaScript (demo)
Source code on GitHub

Language detector

Context
Python bootcamp exercise: identify the language of a text without a dictionary, from its letters alone.
Goal
Recognise the language of a text among ten, by comparing the frequency of its letters with the known frequencies of each language.
Key takeaway
A statistical method needs volume: reliable from two sentences on, it hesitates on a few words. Accents also skewed the count, so I reduce them to their base letter before the analysis. The demo reuses the Python program, ported to JavaScript.
Skills and technologies
  • Python
  • Dictionaries
  • Statistics
  • Unicode
  • JavaScript (demo)
Source code on GitHub

At least 80 letters for a reliable result: the method relies on statistics.
