Games

Snake game

  • Python
  • Pygame
  • Keyboard events
  • Collisions
  • Code split into modules
Goal
Develop a complete Snake: keyboard movement, collisions, apples, score and visual effects. The playable version here is adapted to JavaScript.
Key takeaway
Personal project, built after Hangman to move from turn-based to real time. Real time forces a clear split between the game loop, the display and the rules. The code is divided into modules (snake, apple, collisions, score): a rule can be fixed without touching the rest.

Algorithms

Caesar and Vigenère ciphers

  • Python
  • Algorithms
  • Strings
  • Frequency analysis
  • JavaScript (demo)
Goal
Encrypt and decrypt a message with Caesar (fixed shift) and Vigenère (shift given by a keyword), and recover a Caesar key on its own through frequency analysis.
Key takeaway
Python bootcamp exercise. The modulo wraps the alphabet from "z" back to "a", and decrypting means shifting the other way: a single function handles both operations. To break Caesar, I reused the frequency comparison from the language detector: try all 26 keys and keep the text closest to French.
Source code

Language detector

  • Python
  • Dictionaries
  • Statistics
  • Unicode
  • JavaScript (demo)
Goal
Recognise the language of a text among ten, by comparing the frequency of its letters with the known frequencies of each language.
Key takeaway
Python bootcamp exercise, without a dictionary: only the letters count. A statistical method needs volume: reliable from two sentences on, it hesitates on a few words. Accents also skewed the count, so I reduce them to their base letter before the analysis. The demo reuses the Python program, ported to JavaScript.
Source code
