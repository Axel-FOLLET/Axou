01 / PROJETS

Mes projets techniques

Trois projets, trois étapes : les jeux Python ont posé les bases de la programmation, le site CV celles du web. Pour chacun : le contexte, l'objectif, ce que j'en retiens, les technologies, et les liens pour vérifier par vous-même.

Site web de mon CV

Contexte
Projet Epitech (Web Day 04-05) : concevoir un site CV en HTML, CSS et JavaScript, sans framework, en français et en anglais.
Objectif
Présenter mon passage de la gestion de projets RH à l'informatique sur un site responsive, interactif et bilingue, avec un formulaire de contact fonctionnel.
Ce que j'en retiens
Un site maintenable se construit par petits modules : un fichier par responsabilité (menu, cubes, formulaire, jeux) garde chaque correction localisée. Les dernières itérations ont porté sur l'accessibilité : navigation au clavier, mouvement réduit, validation du formulaire.
Compétences et technologies
  • HTML
  • CSS
  • JavaScript
  • Responsive
  • Animations 3D en CSS
  • Formspree
  • GitHub Pages

Jeu du Snake

Contexte
Projet personnel, réalisé après le Pendu pour passer d'un jeu au tour par tour à un jeu en temps réel.
Objectif
Développer un Snake complet : déplacements au clavier, collisions, pommes, score et effets visuels. La version jouable ici est adaptée en JavaScript.
Ce que j'en retiens
Le temps réel impose de séparer la boucle de jeu, l'affichage et les règles. Le code est découpé en modules (serpent, pomme, collisions, score) : une règle se corrige sans toucher au reste.
Compétences et technologies
  • Python
  • Pygame
  • Événements clavier
  • Collisions
  • Organisation en modules
Code source sur GitHub

Jeu du Pendu

Contexte
Premier projet personnel, réalisé pour mettre en pratique les bases de Python sur un programme complet.
Objectif
Créer un Pendu jouable de bout en bout : tirage d'un mot, saisie des lettres, gestion des erreurs et sauvegarde du meilleur score.
Ce que j'en retiens
Passer d'exercices isolés à un programme complet : lire une liste de mots dans un fichier, conserver un score d'une partie à l'autre et anticiper les saisies invalides.
Compétences et technologies
  • Python
  • Pygame
  • Conditions et boucles
  • Fonctions
  • Lecture de fichiers
