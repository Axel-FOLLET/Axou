Jeux

Jeu du Snake

  • Python
  • Pygame
  • Événements clavier
  • Collisions
  • Organisation en modules
Objectif
Développer un Snake complet : déplacements au clavier, collisions, pommes, score et effets visuels. La version jouable ici est adaptée en JavaScript.
Ce que j'en retiens
Projet personnel, réalisé après le Pendu pour passer du tour par tour au temps réel. Le temps réel impose de séparer la boucle de jeu, l'affichage et les règles. Le code est découpé en modules (serpent, pomme, collisions, score) : une règle se corrige sans toucher au reste.

Jeu du Pendu

  • Python
  • Pygame
  • Conditions et boucles
  • Fonctions
  • Lecture de fichiers
Objectif
Créer un Pendu jouable de bout en bout : tirage d'un mot, saisie des lettres, gestion des erreurs et sauvegarde du meilleur score.
Ce que j'en retiens
Mon premier projet personnel et mon premier programme complet : lire des mots dans un fichier, garder le meilleur score, anticiper les saisies invalides. Je l'ai repris une fois Pygame maîtrisé pour en faire un jeu concret, avec une vraie interface graphique.

Algorithmique

Chiffrements de César et de Vigenère

  • Python
  • Algorithmique
  • Chaînes de caractères
  • Analyse de fréquences
  • JavaScript (démo)
Objectif
Chiffrer et déchiffrer un message avec César (décalage fixe) et Vigenère (décalage donné par un mot-clé), et retrouver seul la clé d'un César par l'analyse des fréquences.
Ce que j'en retiens
Exercice de la piscine Python. Le modulo fait boucler l'alphabet de « z » à « a », et déchiffrer revient à décaler dans l'autre sens : une seule fonction sert aux deux opérations. Pour casser César, j'ai réutilisé la comparaison de fréquences du détecteur de langue : essayer les 26 clés et garder le texte le plus proche du français.
Code source

Détecteur de langue

  • Python
  • Dictionnaires
  • Statistiques
  • Unicode
  • JavaScript (démo)
Objectif
Reconnaître la langue d'un texte parmi dix, en comparant la fréquence de ses lettres aux fréquences connues de chaque langue.
Ce que j'en retiens
Exercice de la piscine Python, sans dictionnaire : seules les lettres comptent. Une méthode statistique a besoin de volume : fiable dès deux phrases, elle hésite sur quelques mots. Les accents faussaient aussi le comptage ; je les ramène à leur lettre de base avant l'analyse. La démo reprend le programme Python, porté en JavaScript.
Code source

Au moins 80 lettres pour un résultat fiable : la méthode repose sur des statistiques.
